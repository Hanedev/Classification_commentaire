# Classification de commentaires — NLP

Projet académique de classification de sentiments sur des critiques de films du jeu de données IMDB.

## Objectif

Construire un pipeline NLP permettant de classer des commentaires en **positif** ou **négatif**.

## Approche

Le notebook comprend notamment :

- chargement du jeu de données IMDB ;
- nettoyage et préparation du texte ;
- utilisation de spaCy et NLTK ;
- tokenisation ;
- apprentissage de représentations Word2Vec ;
- construction de vecteurs de commentaires ;
- séparation entraînement / test ;
- classification avec une régression logistique ;
- évaluation avec `accuracy_score` et `classification_report`.

## Stack

- Python
- spaCy
- NLTK
- Gensim / Word2Vec
- scikit-learn
- Pandas / NumPy
- Jupyter / Google Colab
